**Part engineer, part consultant.** I build AI products with clients and make sure they understand and trust what gets built. Data Analyst → ML Engineer → AI Engineer. 🌐 [nathanvu.vercel.app](https://nathanvu.vercel.app)

AI can write the code. Someone still has to understand the problem, talk to the people, question the output and turn it into something useful. That's the part I enjoy most.
